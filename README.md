# 인공지능과 인문학 최종 코드 실행 가이드
코드 개발: [IROLIM](https://github.com/poet-developer)

## 1) CLI 접속
본 프로젝트는 **터미널(CLI)** 환경에서 명령어를 실행하여 구동합니다.

## 2) 환경 변수 관리 (필수)
- Google API 키 및 관련 인증 정보는 **코드에 직접 하드코딩하지 않습니다.**
- `.env` 등 환경 변수 파일에 저장한 후 로드하여 사용합니다.
- 가능하면 **암호화 또는 비밀 관리 도구**를 활용하여 안전하게 보관합니다.

## 3) 보안 원칙
- API 키가 포함된 파일(`.env`, credential 파일 등)은 **Git에 커밋하지 않습니다.**
- 반드시 `.gitignore`에 등록합니다.
- 저장소에는 키가 제거된 **`.env.example` 파일만 제공**합니다.
